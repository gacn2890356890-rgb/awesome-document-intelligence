# Tools and resources

## Open-source document systems

- [Docling](https://github.com/docling-project/docling) — document conversion and structured export.
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) — OCR, layout, table, and document pipelines.
- [MinerU](https://github.com/opendatalab/MinerU) — PDF and document content extraction.
- [Surya](https://github.com/datalab-to/surya) — OCR, layout analysis, and reading-order resources.
- [Marker](https://github.com/datalab-to/marker) — document-to-markdown conversion.
- [Pix2Text](https://github.com/breezedeus/Pix2Text) — text, formula, and table extraction.

## Public model families and projects

- [LayoutLM family](https://github.com/microsoft/unilm/tree/master/layoutlmv3) — multimodal document pretraining.
- [Qwen-VL](https://github.com/QwenLM/Qwen2.5-VL) — general multimodal models with document capabilities.
- [InternVL](https://github.com/OpenGVLab/InternVL) — open multimodal model family.
- [Donut](https://github.com/clovaai/donut) — OCR-free document understanding.
- [Nougat](https://github.com/facebookresearch/nougat) — scientific document conversion.
- [olmOCR](https://github.com/allenai/olmocr) — open PDF-to-text pipeline.

## Maintenance notes

This list distinguishes a public project link from a verified benchmark result. Users should check repository activity, checkpoint availability, model/data licenses, security posture, and reproducibility before deploying any system.
