# Curated reading list

This is a compact, source-traceable starting path. The complete survey bibliography is in [`../references/survey-references.bib`](../references/survey-references.bib).

## Surveys and field maps

- [Document Layout Analysis: A Comprehensive Survey](https://arxiv.org/abs/2303.14227) — layout-analysis taxonomy and challenges.
- [Deep Learning Based Visually Rich Document Content Understanding: A Survey](https://arxiv.org/abs/2211.13187) — visually rich document understanding.
- [Document Parsing Unveiled](https://arxiv.org/abs/2410.21169) — recent parsing techniques and open problems.
- [Large Language Models in Document Intelligence](https://arxiv.org/abs/2501.00489) — LLM/VLM direction and limitations.

## Layout and structured document pretraining

- [LayoutLM](https://doi.org/10.1145/3394486.3403172) — joint text and layout pretraining.
- [LayoutLMv2](https://aclanthology.org/2021.findings-acl.201/) — multimodal pretraining for visually rich documents.
- [LayoutLMv3](https://aclanthology.org/2022.acl-long.250/) — unified text-image masking.
- [DocFormer](https://openaccess.thecvf.com/content/ICCV2021/html/Appalaraju_DocFormer_End-to-End_Transformer_for_Document_Understanding_ICCV_2021_paper.html) — end-to-end multimodal document understanding.
- [LiLT](https://aclanthology.org/2022.acl-long.534/) — language-independent layout transformer.

## OCR-free and generative parsing

- [Donut](https://arxiv.org/abs/2111.15664) — OCR-free document understanding transformer.
- [Nougat](https://arxiv.org/abs/2308.13418) — neural optical understanding for academic documents.
- [Pix2Struct](https://proceedings.mlr.press/v202/kantorov-23a.html) — screenshot parsing as visual-language pretraining.
- [DocLLM](https://aclanthology.org/2024.acl-long.463/) — layout-aware generative document understanding.
- [Qwen2.5-VL](https://arxiv.org/abs/2502.13923) — general-purpose VLM with document/OCR capabilities.

## Datasets and benchmarks

- [PubLayNet](https://arxiv.org/abs/1908.07836) — large-scale document layout detection.
- [DocBank](https://arxiv.org/abs/2006.01038) — document layout analysis with token-level annotations.
- [TableBank](https://arxiv.org/abs/1903.01949) — table detection and structure recognition.
- [DocVQA](https://arxiv.org/abs/2007.00398) — visual question answering on documents.
- [FUNSD](https://guillaumejaume.github.io/FUNSD/) — form understanding.
- [DocLayNet](https://arxiv.org/abs/2206.01062) — human-annotated page-layout benchmark.
- [OmniDocBench](https://arxiv.org/abs/2412.07626) — end-to-end document parsing benchmark.

## Efficient and open document systems

- [Docling](https://github.com/docling-project/docling) — open-source document conversion toolkit.
- [olmOCR](https://github.com/allenai/olmocr) — PDF-to-text extraction using vision-language models.
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) — OCR and document-analysis toolkit.
- [MinerU](https://github.com/opendatalab/MinerU) — document content extraction toolkit.
- [Surya](https://github.com/datalab-to/surya) — multilingual OCR and document analysis toolkit.

## Agents and world-model connections

- [ReAct](https://openreview.net/forum?id=WE_vluYUL-X) — reasoning and acting with language models.
- [RAP](https://aclanthology.org/2023.emnlp-main.507/) — language-model reasoning as planning with a world model.
- [LLM-DM](https://arxiv.org/abs/2308.10236) — constructing and using language-induced world models for planning.
- [mDocAgent](https://arxiv.org/abs/2503.13964) — multi-modal multi-agent document understanding.
- [OCR Hinders RAG](https://openaccess.thecvf.com/content/ICCV2025/html/Zhang_OCR_Hinders_RAG_Evaluating_the_Cascading_Impact_of_OCR_on_Retrieval-Augmented_Generation_ICCV_2025_paper.html) — measuring downstream retrieval effects of OCR errors.
