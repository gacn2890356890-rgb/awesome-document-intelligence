## Reference repository

- [Awesome VLA](https://github.com/yueen-ma/awesome-vla) was used as the organizational reference.
- Reused design patterns: short definition section, linked contents, taxonomy, timeline, component sections, related repositories/surveys, and a citation block.
- The document-intelligence repository is independent and does not copy the reference repository's content.

## Local source selection

- The current AIR submission source and its 263-entry BibTeX bibliography were used as the manuscript-grounded source set.
- The 10 submitted figures were copied unchanged into `figures/`.
- Private local paths and submission-session details were not placed in the public-facing files.

## Public source policy

- Prefer official proceedings, ACL Anthology, CVF, PMLR, ACM, IEEE, OpenReview, arXiv, DBLP, benchmark pages, and official code repositories.
- Every resource entry should have a stable public link.
- No leaderboard number is included unless its evaluation protocol is traceable.
