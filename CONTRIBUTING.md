# Contributing

Thank you for helping maintain this document-intelligence resource.

## Adding a paper or dataset

Open a pull request that includes:

1. the canonical title and author list;
2. publication year and venue or public preprint status;
3. a stable link to the paper, project page, dataset, or code;
4. one taxonomy category;
5. a short description of the contribution;
6. known license, access, and evaluation limitations.

Prefer official proceedings, ACL Anthology, CVF, PMLR, ACM, IEEE, OpenReview, arXiv, DBLP, or an official project page. Do not add private drafts, personal data, unverifiable leaderboard claims, or unsupported numbers.

## Updating an entry

Keep the original link when it remains valid. If a preprint becomes a proceedings paper, add the proceedings link and preserve the preprint link as a secondary source.

## Figure policy

Survey figures in `figures/` are retained as manuscript assets. Do not edit, crop, or re-color them in a pull request without recording the change and checking the source manuscript.
